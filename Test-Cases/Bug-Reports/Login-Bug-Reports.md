Login Page – Bug Reports

Bug Report 1

Bug ID: BUG_001

Bug Title: Login button accepts invalid password.

Module: Login Page

Severity: High

Priority: High

Precondition: User must have a registered account.

Steps to Reproduce:

Open the login page.

Enter a valid username.

Enter an incorrect password.

Click the Login button.

Expected Result: The application should display an error message and prevent login.

Actual Result: The application allows the user to log in with an incorrect password.

Status: Open

Bug Report 2

Bug ID: BUG_002

Bug Title: Password is displayed in plain text.

Module: Login Page

Severity: Medium

Priority: Medium

Steps to Reproduce:

Open the login page.

Enter a password in the password field.

Expected Result: The password should be masked.

Actual Result: The password is visible in plain text.

Status: Open
